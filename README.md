Desenvolvi um painel gerencial para um e-commerce com o objetivo de analisar suas vendas e traçar estratégias para melhorar seus resultados.  

Utilizei duas bases de dados: uma com informações sobre as vendas e outra com dados dos clientes. Com essas informações, criei duas páginas que permitem aos analistas visualizarem as principais métricas de forma clara e intuitiva.  

As métricas incluídas no painel são:  
- Quantidade total e valor total das vendas  
- Cotação e valor total de vendas por data  
- Quantidade e valor total de vendas por categoria  

Além disso, implementei filtros para proporcionar a melhor experiência ao usuário. O painel foi desenvolvido com foco em um storytelling eficiente e um layout atrativo, garantindo uma interface intuitiva e funcional.
